# 위키화는 페이지 커밋 전이면 되감고, 채팅 이웃은 page.links 로, 그림은 대체 텍스트만

## Context

`nashsu/llm_wiki`(GPLv3 — 화면·기능만 참고, 코드는 보지도 옮기지도 않는다)와 이 앱을 견줘 격차를 뽑았다.
그중 지금 넣은 것은 셋이다: 취소·실패한 위키화가 자료를 대기함으로 돌려놓기, 채팅 근거에 링크 이웃 싣기,
워드·파워포인트 그림의 대체 텍스트 남기기. 나머지는 계약 변경이나 기존 결정 번복이 먼저라 미뤘다.

## Findings

- 위키화를 취소하거나 초안 없이 실패하면 보관함이 작업 브랜치에 남았다. 사유 문구는 "다시 위키화해 주세요"인데
  실제로는 승인 화면에서 빈 병합을 해야 풀렸고, 그 뒤 그 자료는 다시 위키화할 길이 없었다.
- 채팅 근거는 BM25 단독이라 질문과 글자가 안 겹치는 관련 문서를 놓쳤다.
- 그래프(`buildGraph`)는 출처 공유 쌍 O(n²) + Louvain 이라 질문마다 돌릴 수 없고, 그 간선은 레이아웃용 가중치다.
- mammoth 는 워드 그림의 대체 텍스트(`descr`, 비면 `title`)를 `img` 의 `alt` 로 싣는다. 파워포인트는
  슬라이드 XML 의 `p:cNvPr` 에 같은 속성이 있다. 둘 다 그림 바이트를 열지 않고 읽힌다.

## Decisions

- **되감기 범위는 페이지가 커밋되기 전까지만.** 취소·초안 없음·초안 전부 탈락·초안/조립 예외에서 작업 브랜치를
  지우고 자료를 대기함으로 돌려놓는다. 페이지가 커밋된 뒤의 실패는 승인에 남긴다 — 읽을 수 있는 결과다.
- **되감기는 읽어 두고 `checkout` 한 뒤 되살린다.** `reset --hard`·`clean` 은 앱 밖에서 고친 파일을 지운다.
  원문을 전부 되살린 뒤에만 브랜치를 지우고, 중간에 실패하면 작업 브랜치로 돌아가 지금 동작(승인에서 정리)으로 떨어진다.
- **커밋 전 변경이나 시작 커밋 말고 다른 커밋이 있으면 되감지 않는다.** 반쯤 쓰인 위키 파일이 기본 브랜치로 딸려 가
  다음 자동 저장에 섞이는 것, 앱 밖 도구의 커밋이 브랜치와 함께 사라지는 것을 막는다.
- **앱 종료로 갇힌 작업 브랜치는 다음 위키화가 시작하며 되감는다.** 조건은 "기본 브랜치 대비 변경이 전부
  `Clippings/`·`raw/` 아래"다. 미루면 이 변경이 고치려는 막다른 길이 앱 종료 경로에 그대로 남는다.
  비용은 하나 — 대기함 파일이 커밋 전이었으면 원래 이름이 기록에 없어 `raw/` 의 정규화된 이름으로 돌아온다.
- **채팅 이웃의 자료원은 `page.links` 다.** 역링크와 같은 입력을 한 번 돌아 양방향 인접을 만든다(O(N+E)).
  1홉만, 적중 상위 5개의 이웃을 5개까지, 목차·토픽 페이지는 뺀다.
- **이웃 동점은 이어진 문서가 적은 쪽이 먼저다.** 문서 목록에는 일일 노트 같은 허브도 들어 있어 이름순이면 허브가 임의로 뽑힌다.
- **이웃 제외 목록은 `LINT_EXEMPT` 를 import 한다.** 같은 세 경로의 네 번째 사본을 만들지 않는다.
- **그림 자리표는 함수 둘(`imageMark`·`stripImageMarks`)이 정본이다.** `/g` 정규식을 export 하면 `lastIndex` 가
  호출 사이에 남는다. 대체 텍스트는 외부 입력이라 줄바꿈을 접고 `]`·`|` 를 빼고 200자에서 자른다.

## Rejected

- **`buildGraph` 가중치로 채팅 이웃 뽑기** — 질문마다 돌리기엔 비싸고 간선이 정본이 아니다.
- **모든 실패에서 되감기** — 커밋된 초안까지 버리게 된다.
- **한글(.hwpx·.hwp) 대체 텍스트** — `hp:pic` 의 설명 요소 구조를 확인하지 않았다(미검증).
- **그림 파일 보존·위키화 때 그림 읽기** — "그림·포함 개체는 풀지도 세지도 않는다"는 기존 결정을 뒤집어야 한다.

## Open

- 위키화 안 된 `raw/` 원본(건너뛴 자료·거절한 자료)을 다시 돌리는 길은 아직 없다.
- 중복 판정 보강(URL 정규화·내용 해시)은 vault-kit 계약 변경이 먼저다.
- 엔진이 두 번 실패하면 초안 단계가 사유 없이 빈 초안을 돌려줘 "초안을 하나도 쓰지 못했어요"로 뭉개진다(기존 동작).
- 구조 페이지 목록이 네 군데(`lint`·`graph`·`review-service`·`pipeline`)에 따로 있다.
