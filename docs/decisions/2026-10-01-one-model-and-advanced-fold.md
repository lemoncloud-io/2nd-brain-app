## Context

nashsu/llm_wiki 와 원본 2nd-brain 을 다시 대조하고, 앱에서 뺄 것과 더할 것을 사용자와 grilling 으로 정했다.
전제는 "개발자도 쓰지만 비개발자가 우선"이다. 설정 화면에는 엔진·로그인 옆에 용도별 모델 4칸(채팅·위키화·웹 조사·
AI 점검), 채팅이 참고할 문서 양, MCP 서버(JSON·명령 한 줄·환경 변수), 고급 표시가 펼쳐져 있었다. 비개발자가 처음
보는 화면에 개발자용 입력란이 섞여 있었다.

## Decisions

- **MCP 서버는 뺀다고 했다가 유지로 바꿨다.** 사용자: "이거는 개발자도 사용할거야. mcp같은건 있으면 좋겠는데."
- **개발자 손잡이는 설정 맨 아래 '고급' 하나에 접는다.** 넣는 것: 모델 직접 입력, MCP 서버, 채팅이 참고할 문서 양
  (기본 '보통'), 고급 표시, AI 프로그램 위치, 화면 배치 되돌리기. 보관함 상태 되돌리기는 밖에 둔다. 위키화가 도중에
  멈췄을 때 오류 안내가 비개발자를 그 버튼으로 보낸다.
- **켜 둔 MCP 서버나 목록에 없는 모델이 있으면 고급은 펼친 채로 열린다.** 쓰고 있는 값이 접힌 칸 뒤에 숨지 않게.
  접어도 내용은 지우지 않고 숨긴다. 쓰다 만 MCP 입력이 사라지지 않게.
- **모델은 하나다.** 채팅·위키화·웹 조사·AI 점검이 같은 모델을 쓴다. 2026-09-15 에 사용자가 고른 용도별 모델
  ("능력 차등화")을 이번에 사용자가 뒤집었다. 기본 화면은 목록(fable·opus·sonnet)만 보이고, 목록에 없는 이름은
  고급에서 넣는다.
- **옛 설정 파일은 채팅 모델을 이어받는다.** `models.chat` 만 이어받고, 다른 용도 값은 버린다. 위키화 모델을 채팅에
  쓰면 고른 적 없는 모델이 된다. 옛 `models` 키는 다음에 고를 때 지운다.
- **엔진과 모델은 고르는 즉시 저장한다. 저장 단추는 없다.** 저장이 도는 동안은 단추와 목록을 잠근다.
- **엔진을 바꾸면 모델은 기본으로 돌아간다.** Claude 별칭을 Codex 가 모르기 때문이다. 시작하기의 엔진 전환도 같은
  경로(`switchEngine`)를 탄다.

## Rejected

- **용도별 모델 유지** — 고를 칸 넷이 비개발자 첫 화면을 차지하는데, 대부분 같은 값을 넣는다.
- **MCP 설정 삭제** — 개발자가 쓰고, 고급 접기 안에서는 비개발자 화면을 무겁게 하지 않는다.
- **엔진은 즉시 저장, 모델은 저장 단추** — 리뷰에서 결함 두 가지가 나왔다. 엔진 저장이 도는 사이 저장 단추를 누르면
  옛 엔진이 다시 써졌다. 고급의 직접 입력은 화면에만 바뀐 엔진에 맞지 않는 이름을 붙였다. 한 카드에 저장 규칙이
  둘인 것도 UI 리뷰가 지적했다.
- **접을 때 내용을 화면에서 지우기** — MCP 입력 초안이 접는 순간 사라졌다.

## Open

- 컨트롤 테두리 토큰(`border-hairline`)의 대비가 비텍스트 3:1 에 못 미칠 수 있다(렌더 측정 안 함, 기존 문제).
- KaTeX_Size3 폰트가 빌드에서 `data:` 로 인라인돼 CSP `default-src 'self'` 에 막힌다. 모든 화면에서 콘솔 오류가
  나고, 큰 괄호 글꼴이 빠질 수 있다(기존 문제, 이번 변경과 무관).
